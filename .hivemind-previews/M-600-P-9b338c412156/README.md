# DeFi Protocol Landing Page

## Overview
This project is a landing page for a decentralized finance (DeFi) protocol, showcasing its features and providing user onboarding.

## Installation
1. Clone the repository.
2. Navigate to the `frontend` directory and run:
   ```bash
   npm install
   npm run dev
   ```
3. Navigate to the `backend` directory and run:
   ```bash
   npm install
   node server.js
   ```

## Usage
- Access the frontend at `http://localhost:3000`
- The backend API runs on `http://localhost:5000`

## Features
- User-friendly interface
- Comprehensive overview of protocol features
- Contact form for user inquiries
