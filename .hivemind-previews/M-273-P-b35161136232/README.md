# Snake Game Web App

This is a fully functional Snake game web application built with React, Vite, and Tailwind CSS.

## Features
- Responsive design
- Intuitive controls
- Leaderboard for high scores

## Installation

### Frontend
1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Backend
(Currently not implemented)

## Build
To build the frontend for production, run:
```bash
npm run build
```
