# Snake Game

This repository contains a classic Snake game implemented with a React frontend and a Node.js backend.

## Installation

### Frontend
1. Navigate to the `frontend` directory.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

### Backend
1. Navigate to the `backend` directory.
2. Install dependencies: `npm install`
3. Start the server: `npm start`

## Usage
- Access the game at `http://localhost:3000/game`.
- View instructions at `http://localhost:3000/instructions`.

## Features
- Classic Snake gameplay with arrow key controls.
- Score tracking and display.
- Instructions page with game controls and rules.
