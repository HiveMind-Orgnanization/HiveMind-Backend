# DeFi Protocol Landing Page

## Overview
This project is a production-ready landing page for a DeFi protocol on an EVM-compatible blockchain.

## Installation
1. Clone the repository.
2. Navigate to the `frontend` directory and run:
   ```bash
   npm install
   npm run dev
   ```
3. Navigate to the `backend` directory and run:
   ```bash
   npm install
   node server.js
   ```

## Usage
- Access the frontend at `http://localhost:3000`
- The backend API is available at `http://localhost:5000/api`
