# DEX Dashboard

## Overview
This project implements a decentralized exchange (DEX) dashboard providing users with real-time data and analytics.

## Installation
1. Clone the repository.
2. Navigate to the `frontend` directory and run:
   ```bash
   npm install
   npm run dev
   ```
3. Navigate to the `backend` directory and run:
   ```bash
   npm install
   npm start
   ```
4. Access the dashboard at `http://localhost:3000`.

## Features
- Real-time price feeds
- Portfolio overview
- Basic trading volume charts
