# Ludo Game

This is a fully functional Ludo game built with a React frontend and Node.js backend.

## Installation

### Frontend

```bash
cd frontend
pnpm install
pnpm dev
```

### Backend

```bash
cd backend
pnpm install
pnpm start
```

## Features
- User authentication with JWT
- Real-time gameplay with Socket.io
- Game lobby for joining and creating games
- Interactive game board

## Tech Stack
- Frontend: React, Vite
- Backend: Node.js, Express, MongoDB
- Real-time: Socket.io
